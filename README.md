🍔 Ctrl+Alt+Burguer

Ctrl + Alt + Fome? Reinicie!

O Ctrl+Alt+Burguer é um sistema de Ponto de Venda (PDV) desenvolvido em Java para uma hamburgueria fictícia. O projeto tem como objetivo aplicar conceitos de programação, organização de código, manipulação de arquivos e controle de dados por meio de um sistema executado diretamente no terminal.

O sistema permite gerenciar produtos, clientes, vendedores, vendas e estoque, além de calcular comissões e impostos acadêmicos e gerar recibos e relatórios.

🎯 Objetivos do projeto

- Desenvolver um sistema funcional utilizando Java.
- Praticar programação orientada a objetos.
- Implementar cadastros e operações de venda.
- Automatizar o controle de estoque.
- Armazenar e recuperar informações por meio de arquivos TXT.
- Trabalhar em equipe com divisão de tarefas, integração e testes.

⚙️ Funcionalidades

- Gerenciamento de produtos: cadastro, listagem e consulta do cardápio.
- Gerenciamento de clientes: cadastro e consulta de clientes.
- Gerenciamento de vendedores: cadastro e consulta de vendedores.
- Registro de vendas: seleção de produtos, quantidades, cliente e vendedor.
- Controle automático de estoque: atualização das quantidades após a confirmação de uma venda.
- Combos: venda de combinações de produtos com baixa automática dos itens componentes.
- Cálculos automáticos: comissão de 5% para o vendedor e impostos acadêmicos de 25%, conforme as regras definidas no projeto.
- Recibos: exibição dos detalhes e valores da venda.
- Relatórios: consulta de vendas, faturamento, estoque, comissões e impostos.
- Persistência em arquivos TXT: armazenamento dos dados para utilização em execuções futuras.

🍟 Cardápio

O sistema contará com 12 opções comerciais, divididas em quatro categorias:

- Hambúrgueres: Bug Simples, Ctrl+C Cheddar, Ctrl+V Bacon, Stack Overflow e Blue Screen.
- Acompanhamentos: Batata.exe e Onion Rings 404.
- Bebidas: Coca-Cola, Guaraná Antarctica e água mineral.
- Combos: Ctrl+Alt+Fome e Combo Boss Final.

Os produtos possuem códigos identificadores e preços predefinidos para facilitar o cadastro, a consulta e o registro das vendas.

🛠️ Tecnologias e ferramentas

- Java — linguagem de programação.
- IDE de desenvolvimento — VS Code.
- Terminal — interface de execução e interação com o usuário.
- Arquivos TXT — armazenamento e persistência dos dados.
- Git e GitHub — versionamento, colaboração e organização do projeto.

«O projeto foi planejado para utilizar arquivos TXT, sem exigir um banco de dados SQL.»

📂 Organização sugerida

A estrutura poderá ser organizada em classes Java responsáveis por cada parte do sistema, como:

- "Main" — inicialização do programa.
- "Menu" — navegação pelas opções.
- "Produto" — informações dos produtos.
- "Cliente" — dados dos clientes.
- "Vendedor" — dados dos vendedores.
- "Venda" e "ItemVenda" — registro das vendas e seus itens.
- "Estoque" — consulta e atualização das quantidades.
- "PersistenciaTXT" — leitura e gravação dos arquivos.
- "Relatorios" — geração dos relatórios.

Os dados poderão ser armazenados em arquivos como "produtos.txt", "clientes.txt", "vendedores.txt", "estoque.txt" e "vendas.txt".

👥 Desenvolvimento em equipe

O desenvolvimento será organizado em um cronograma de oito semanas, com responsabilidades rotativas entre os integrantes. A proposta é que todos participem do planejamento, implementação, integração, testes e apresentação, adquirindo conhecimento sobre o funcionamento geral do sistema.

📚 Finalidade acadêmica

Este projeto possui finalidade educacional e busca consolidar conhecimentos de programação em Java por meio de uma aplicação prática. As taxas de comissão e impostos são regras acadêmicas definidas para o exercício, não uma representação de cálculo tributário real.
