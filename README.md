# ProjetoPDV
O Ctrl+Alt+Burguer é um sistema de ponto de venda (PDV) desenvolvido em Java para uma hamburgueria fictícia. Permite gerenciar produtos, clientes, vendedores, vendas e estoque, além de gerar recibos e relatórios. Os dados são armazenados em arquivos TXT, sem necessidade de banco de dados. Projeto acadêmico.
